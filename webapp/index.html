About this tool

Clinical LiDAR uses calibrated digital planimetry measures—area, perimeter, longest/widest dimensions—and reports percentage area reduction alongside linear edge change. The image signal is a comparability aid. This browser route uses photos; true device depth remains separate through native device adapters and the depth-grid workflow.
